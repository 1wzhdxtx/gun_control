# 民用枪支全链条智慧监管 · 网页演示层

四个角色工作台的 FastAPI 演示版，复用 `gunreg` 后端（制造→领用→运输→报废→预警→链上追溯），
内置模拟数据（首次启动或显式设置 `GUNREG_RESET=1` 时重建），按设计文档四工作台矩阵展开：
**监管（全量/审批/取证）· 单位（领用归还/申报/制造）· 从业人员（档案/资格）· 审计（账本/审计/对账）**。

业务主线：**五类业务场景 + 一枪一档 + 跨部门全生命周期监管**。

- **五类场景**（民用猎枪 / 射击运动 / 机场驱鸟 / 野生动物麻醉 / 营业性射击场）是业务入口与筛选维度，
  不替代枪械类型字段；各场景带自己的业务信息字段（机场驱鸟「适用规定」标注 **待核实**）。
- **全生命周期监管总览**（监管台首页）：五类场景入口、主线各阶段数量、待审批事项、检查整改情况。
- **一枪一档**（`archive.html?code=`）：主线节点
  企业资质与计划 → 制造赋码 → 配购与配售 → 运输交接 → 持有使用 → 报废销毁（+ 进出境条件分支），
  节点统一显示办理事项 / 申请单位 / 办理部门 / 经办人 / 办理时间 / 审批意见 / 证件及有效期 /
  附件 / 存证编号，状态为 已完成 / 办理中 / 待办理 / 退回补正 / 不适用，并区分真实业务记录与演示记录。
- **协同审批**：哪个部门办理、当前由谁处理、缺什么材料、审批结果；审批规则（部门链 / 材料 / 依据）
  可配置——制造许可由**国务院公安部门**核发、配售许可由**省级公安机关**核发（枪支管理法第十五条，
  两类许可分开发证），狩猎场配置猎枪按**林业行政主管部门批准 → 省级公安审批 → 设区的市级公安
  核发配购证件**三级链（第九条），三种口径分立不合并。
- **部门分权**：公安（部/省/市三级）、林业林草、体育、海关按事项与辖区办理，通用管理员不能包办；
  运输审批/核销与报废确认销毁为**公安专属**（非公安部门即使 admin 角色也 403）；
  前置条件（配售配购登记、企业证照、生产计划）未满足时后台直接阻止领用 / 运输 / 进出境 / 制造赋码。
- **监督检查**：检查单位、问题、整改期限、复查结果——待整改 → 待复查 → 已闭环 三态闭环；
  复查须原检查部门显式给出**通过 / 不通过**（不通过退回整改，多轮整改历史留痕）。
- **进出境**：贸易进出口 与 人员携带进出境 分开建项（枪支管理法第三十五至三十七条）。

## 启动

```bash
uv run uvicorn webapp.main:app --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000/login.html

> 使用单进程 uvicorn。默认数据目录为 `webapp/data/`，可通过 `GUNREG_DATA_DIR` 指定独立目录。`GUNREG_RESET=1` 会清空该目录，请只对可丢弃的演示数据使用。当前链账本、审计、密钥仍在内存中，重启不会恢复这些内容；因此重启后不要执行派生视图重建，详见根目录 `CODE_REVIEW.md`。

`GUNREG_DATA_DIR` 指向临时目录。

## 推荐演示路径

1. **监管·五类场景主线**：全生命周期监管总览看五类场景入口 / 各阶段数量 / 待审批 / 检查整改 →
   「一枪一档」打开任一支枪（猎枪 `YNH20260000610`）看主线七节点与统一记录字段（真实/演示记录有标） →
   「协同审批」处理待办：先用 admin1 试办林草节点演示**分权拒绝**，再切 forestry1 办第一步（第九条批准）、
   admin2 办第二步（省级审批）、admin1 办第三步 → 设区的市级核发配购证件并归档 →
   「监督检查」走 检查 → 整改 → 复查（显式通过/不通过）闭环 →
   「进出境」分别演示贸易出口（海关两节点）与携带出境（省级公安 → 海关）。
2. **监管·原有链路**：总览看预警态势 → 推进时钟(+6/24/72h) → 预警中心「扫描超期」→「升级未响应预警」→ 处置闭环；
   运输监管审批 PERMIT-A / 核销 PERMIT-B（关联上游配售）；报废监督走完五节点；一链查证验单枪证据链。
3. **单位**：射击场台账 → 领用/归还（双人签名=保管+监督，服务端验签）；
   > 注意：三级阶梯的持枪人名下都有超期枪，会被时限合约正确阻断新领用——先归还名下超期枪，或在「人员与设备」新增一名无欠账的持枪人再领用（这正是"超期未还阻断流转"的合规演示）。
   - 用 unit-hunt（狩猎场）领用 `YNH20260000610` → **前置条件拦截**（该枪未登记配售配购）；
     「协同审批」里补正 APP-2026-006 材料后提交，跟踪部门链进度；「监督检查」登记本单位整改；
     「配售登记」表单按前置条件校验给出缺哪项（双方资质 / 有效证照 / 枪支归属），补正后可登记交付。
   - 运输申报成功后，回监管台审批、单位「运输申报」起运。
4. **从业人员**：查名下枪支/事件（行内「档案」直达一枪一档）；资格续期/暂停（暂停资格会触发紧急预警并阻断名下枪支流转）。
5. **审计**：审计日志全文检索 + 校验审计链完整性；链上账本区块明细 + 账本校验；单枪证据核验（领域哈希链/链上覆盖/交易比对/规则版本）；派生视图重建；Outbox 泵送与对账。
